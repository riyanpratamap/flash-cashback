# P5.3 code check — Money attempt machine and saved attempts

Verdict: **CHANGES_REQUESTED** (two major, four minor).

Checker's gate: `make mobile-check` exit=0 (13 suites, 147 tests).

Verified (critical-write safety pass):

- Same key on every resend: `check()` only sends `attempt.key`; AC-60, AC-73, AC-74 assert it.
- Saved user as `X-User-ID`: `sendAttempt` uses `attempt.user_id`; tested with user_b selected.
- Save before send: `runPress` awaits `save`; the fetch stub reads `fc:attempts` at call time (AC-72).
- Save error returns `LOCAL_ERROR` and sends nothing (tested).
- Timeout, network error, 5xx keep the attempt; no path reports "failed"; unknown ends in `waiting`, still saved.
- Double press: ref guard set before the first await; the launch check holds it.
- Focus refetch cannot clear the attempt (provider state and ref, never the query cache).

## Maker's assumptions

- Resend timing (press waits first; launch, Check now, Check again send at once; Check again = another round of 3):
  consistent with §10 and AC-60.
- Launch resend ending in `waiting` stops the queue, rest become cards: deviates from §10 (each recent attempt goes to
  checking). Safe; untested (F2a). Raised to the owner as a spec deviation.
- Unreadable `created_at` counts as old: fine, tested.
- Press / Check now ignored while `waiting`: fine, untested (F2b).
- Failed removal after a definite answer ignored: contradicts §5 for a 4xx (F1).
- Unreadable store = no attempts; save error → `LOCAL_ERROR`: consistent with the PRD; launch case untested (F2d).
- Module-level write queue: fine, tested.
- `launchChecked` before resends finish: fine.
- Dismiss history hint left to P5.4: fine.
